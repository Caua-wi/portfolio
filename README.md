Assistente administrativo na Fametro e estudante de Análise e Desenvolvimento de Sistemas em Manaus. Este portfólio reúne minha experiência com o TOTVS RM e projetos inspirados no atendimento acadêmico.

[Abrir o portfólio](https://cauaalmeida.netlify.app/)

## Fila acadêmica

[Experimentar o simulador](https://cauaalmeida.netlify.app/projetos/fila-academica/index.html) · [Consultar o código](projetos/fila-academica/)

O simulador começa com seis chamados fictícios. Ao distribuir o próximo, ele seleciona o chamado mais antigo em espera e o atribui ao técnico com menos atendimentos em aberto. Em caso de empate, usa a ordem alfabética. Concluir um chamado atualiza a carga do técnico.

## Executar localmente

Na pasta do repositório, execute com Python 3:

```sh
python -m http.server 8000
```

Abra [localhost:8000](http://localhost:8000). O site usa HTML, CSS e JavaScript e dispensa instalação de dependências.
